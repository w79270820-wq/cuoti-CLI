# cuoti — 行测错题本 CLI

> 专为国考/省考备考设计的命令行错题管理工具。  
> 艾宾浩斯间隔复习 · Anki 牌组导出 · 本地存储 · 无需注册

## 功能一览

| 功能 | 说明 |
|------|------|
| 📝 添加错题 | 交互式引导，支持科目/错因/标签/来源 |
| 📅 今日复习 | 自动列出到期和逾期题目 |
| 🧠 间隔复习 | 艾宾浩斯曲线（1→2→4→7→15→30→60天）自动调度 |
| 📊 弱点分析 | 按科目/错因分布柱状图 |
| 📤 Markdown 导出 | 含复习进度，可导入 Obsidian/Notion |
| 🃏 Anki 导出 | 生成 `.apkg` 牌组，带样式卡片，直接导入 Anki |

## 快速开始

```bash
# 无需安装依赖，直接运行（纯 Python 标准库）
python cuoti.py --help

# 推荐安装，终端效果更美观
pip install rich click
```

## 典型使用流程

```bash
# 1. 刷完一套题后，把错题录入
python cuoti.py add

# 2. 第二天打开，查看今日复习任务
python cuoti.py due

# 3. 逐题复习，评分后自动安排下次时间
python cuoti.py review 3

# 4. 随时查看备考状态
python cuoti.py stats

# 5. 导出到 Anki，通勤路上继续刷
python cuoti.py anki
```

## 命令说明

```
add                     添加一道错题（交互引导）
due                     今日待复习清单（逾期 + 今天到期）
review <id>             复习一道题
  → 先看题，回车显示答案
  → 按掌握程度评分（完全掌握/基本掌握/模糊记得/完全不会）
  → 自动计算下次复习时间

list                    查看所有错题
list -m 言语理解         按科目筛选
list -e 知识盲区         按错误原因筛选
list -t 主旨题           按知识点标签搜索
list --unreviewed        只看待复习的
list -n 10              只显示最近10条

show <id>               查看题目详情 + 复习历史时间线
stats                   统计与弱点分析
export                  导出为 Markdown（含复习进度）
anki                    导出为 Anki .apkg 牌组
anki -m 数量关系         只导出某科目
anki -t 主旨题           只导出含某标签的题
anki -o file.apkg       自定义文件名
delete <id>             删除错题
```

## 间隔复习机制

基于艾宾浩斯遗忘曲线的7轮复习计划：

```
添加错题 → 第1轮(1天后) → 第2轮(2天后) → 第3轮(4天后)
         → 第4轮(7天后) → 第5轮(15天后) → 第6轮(30天后) → 第7轮(60天后) → 长期记忆 ✓
```

评分影响间隔：
- **完全掌握**：间隔×1.5，加速推进
- **基本掌握**：按标准计划推进
- **模糊记得**：间隔减半，放慢节奏
- **完全不会**：重置到第1轮，明天再来

## Anki 卡片

正面显示题目，背面显示正确答案、解析笔记、知识点标签。
卡片按模块彩色标注（言语/数推/判断/常识/资料各有颜色）。

**导入**：打开 Anki → 文件 → 导入 → 选择 `.apkg` 文件
